Events

Add or change an event

An event is mostly choices. Flyers, sign-up forms, extra credit, assignments, competitions and music are made in their own tabs, then picked here.

Open the event list (new tab) See what students see
  1. Find the event by its date and name, and click it. For a new one, press Add an entry at the bottom of the list.
  2. Fill in the top part: name, campus, date, start and end time, room and a one- or two-sentence description. That is all an event needs.
  3. Pick what it uses: a flyer, music, and switch on a sign-up form, extra credit, an assignment or a competition if it has one. Missing from a list? Make it in its tab first.
  4. Press Save. The events page updates in about a minute. The event code (gvl-1, gvl-2…) is set for you in date order.

Not ready to show it? Choose Not yet (draft). Past events drop off by themselves. Class pages (SPAN 1001, Spanish) update when Daniel next publishes.

Events

Flyers and photos

Any picture or PDF works, phone photos too. Flyers live in their own tab; an event picks one.

Open the Flyers tab (new tab) Browse all uploads
  1. Add an entry in the Flyers tab and give it a name you will recognize.
  2. Upload the file. Any name and type is fine: it becomes a web image named after its event code, and is renamed if the code changes.
  3. Describe the flyer in a sentence or two (what it says and shows). Screen readers read this aloud.
  4. Press Save, then open the event and pick the flyer under Flyer.

Prize photos go in the Competitions tab, music in the Music tab.

Events

Backgrounds

Each event can have a moving background behind its flyer. Pick one for an event, or adjust a background's name and colors.

Edit background colors (new tab)
  1. To choose one for an event: open the event and set Background.
  2. To change colors: open the background and type a color code such as #B4501A. Any color picker online gives you one.
  3. Press Save and check the event page in both light and dark mode.

Keep text colors dark on light pages and light in dark mode so everyone can read them. New drawings are made by Daniel in the Event Generator.

Events

Campuses and rooms

The campus list and each campus's lab room. Students can filter events by campus.

Edit campuses (new tab)
  1. Change a room by opening the campus and typing the new one.
  2. Add a campus with a name, a room and a short code of 2–4 letters (for example gvl).
  3. Press Save.

Don't change a campus's short code once events use it. Events find their campus by that code.

SPAN 1001 site

This semester's pages

The SPAN 1001 site lists this semester's pages in sections, for example "Oral Final". Rename a section, change its dates, or add a page to it.

Edit this semester (new tab) See the SPAN 1001 site
  1. Open a section to change its name or dates, or add a new one at the bottom.
  2. To list a page, add it under Pages in this section with its name, file and a one-line description.
  3. Press Save. The site rebuilds its menus in about a minute.

The page file itself has to be on the site already; this list only adds it to the menu. Exams, answer keys, grades and student work never go on this site.

Start a new semester

This moves this semester's pages to the archive (they keep working) and starts an empty semester. Do it once, after final grades are in.

Start a new semester (new tab)
  1. Pick the season, year and class days.
  2. Turn on "Start it now?" and press Save.
  3. Wait about a minute. The old semester appears under past semesters on the site, and the new one is ready for pages.

D2L links point to the current semester. Update them in the new D2L course after you start the new semester.

Help

Who can edit

Only people Daniel invites can save changes. Anyone can read this help page, but the editor stays locked to everyone else.

Invite to events (new tab) Invite to SPAN 1001
  1. Type their email and send the invite. They don't need a GitHub account.
  2. Send them this page. It's all they need.
  3. To remove someone, open the same list and delete their email.

Invited editors can change content and upload files. Only Daniel can change how the forms work or who is invited.

Help

If something looks wrong

Most problems fix themselves with a refresh. If not, check these.

I saved, but the site hasn't changed.
Wait a minute, then refresh the page. Your browser may be showing an older copy; a private window always shows the newest.
My event doesn't show.
Check that Show it to students? says Yes, the date isn't in the past, and the end time is after the start time.
The flyer shows "Flyer coming soon".
Check the event picks a flyer under Flyer. A new phone photo or PDF can take a minute to be converted.
I changed something by mistake.
Every save is kept. Tell Daniel what you changed and when; he can put the old version back in a minute.
The editor shows an error when I save.
It names the field to fix, for example a color code or an event code in the wrong format. Fix that field and save again.
